# Sketch Out × AI lewat MCP — Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI apa pun yang mendukung MCP (Claude Code, Codex, Claude Desktop, OpenCode, …) bisa membaca dan menggambar di Sketch Out lewat `Sketch Out --mcp`. Pengguna menyambungkannya dari jendela "Hubungkan ke AI…".

**Architecture:**
- `--mcp` adalah penghubung stdio ↔ socket Unix.
- Proses utama menjalankan `McpServer` (SDK resmi) per koneksi socket. Alat memeriksa grant, lalu meneruskan operasi kanvas ke renderer jendela yang menampilkan catatan (`ai:request` / `ai:respond`).
- Renderer menjalankan operasi pada `ExcalidrawImperativeAPI` sebagai satu langkah undo.
- Penulis config per klien ada di main. UI hanya mengirim id klien.

**Tech Stack:** Electron 45, `@modelcontextprotocol/sdk` 1.32.x (dibundel), Excalidraw 0.18.1 (`convertToExcalidrawElements`, `exportToBlob`, `CaptureUpdateAction`), `@excalidraw/mermaid-to-excalidraw`, zod 4, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-26-ai-mcp-design.md`

## Global Constraints
- Tidak ada port jaringan. Socket mode `0600`.
- Setiap path dari AI lolos `assertGranted` / `assertGrantedDir`. Tidak ada alat untuk menghapus atau mengganti nama catatan.
- Satu panggilan alat penyunting = satu langkah undo (`CaptureUpdateAction.IMMEDIATELY`).
- Config klien lain:
  - hanya kunci `sketch-out` yang diubah;
  - tulis atomik;
  - cadangan `<file>.sketchout.bak` sebelum penulisan pertama;
  - file yang gagal di-parse tidak disentuh.
- Renderer tidak pernah mengirim path atau perintah untuk config klien, hanya id dari daftar tetap.
- Batas:
  - `add_elements` ≤ 500 elemen per panggilan;
  - `read_note` ≤ 2.000 elemen;
  - `view_note` sisi terpanjang ≤ 1.600 px;
  - request ke renderer timeout 20 detik;
  - menunggu app terbuka ≤ 15 detik.
- Installer naik ≤ 2 MB dari 93 MB.
- Teks UI dalam bahasa Indonesia.

## Review Focus
1. **App belum terbuka** saat AI memanggil alat: penghubung membuka app lalu menunggu socket. Kalau gagal, setiap request dibalas error JSON-RPC (bukan menggantung).
2. **Catatan belum terbuka / tab lain aktif dengan perubahan yang belum tersimpan:** catatan dibuka sebagai tab dengan aturan flush. Kalau flush gagal, alat membalas error "Catatan lain belum tersimpan".
3. **Config klien yang rusak atau ber-komentar:** tidak disentuh, dan pesannya jelas.
4. **Path di luar grant / symlink keluar / dua jendela menampilkan catatan yang sama:** ditolak, atau diarahkan ke jendela yang terdaftar.
5. **Muat ulang otomatis bersamaan dengan suntingan lokal yang belum tersimpan:** tidak pernah menimpa. Dialog lama yang muncul.

### Task 1: Socket, penghubung `--mcp`, transport

**Files:**
- Create: `src/main/mcp/socketPath.ts`, `src/main/mcp/bridge.ts`, `src/main/mcp/lineTransport.ts`
- Modify: `src/main/index.ts` (cabang `--mcp` paling awal), `package.json` (devDependency `@modelcontextprotocol/sdk`)
- Test: `tests/unit/mcpBridge.test.ts`

**Produces:**
- `socketPath(userData: string, tmp = os.tmpdir()): string`: `<userData>/mcp.sock`; kalau panjangnya > 100, `<tmp>/sketch-out-<sha1(userData) 12 char>.sock`.
- `runBridge(opts: { sockPath: string; stdin: Readable; stdout: Writable; launchApp(): void; waitMs?: number; connect?: (p) => Socket }): Promise<number>` (exit code):
  - sambung. Kalau gagal, `launchApp()` sekali, lalu coba lagi setiap 250 ms sampai `waitMs` (default 15000);
  - pipe dua arah, lalu resolve 0 saat stdin selesai atau socket ditutup;
  - kalau tidak tersambung, baca baris stdin dan balas setiap request ber-`id` dengan `{"jsonrpc":"2.0","id":…,"error":{"code":-32000,"message":"Sketch Out tidak bisa dibuka"}}`, lalu resolve 1 saat stdin selesai.
- `class LineTransport implements Transport` (SDK `@modelcontextprotocol/sdk/shared/transport.js`):
  - dibangun di atas `Duplex` (socket);
  - JSON per baris (`\n`);
  - `start`, `send`, `close`, `onmessage`/`onclose`/`onerror`;
  - baris yang tidak valid memicu `onerror` tanpa crash.
- `index.ts`: kalau `process.argv.includes("--mcp")`:
  - `app.dock?.hide()`;
  - `runBridge` dengan `launchApp` = spawn `process.execPath` dengan argumen yang sama tanpa `--mcp` (detached, `stdio: "ignore"`, env diteruskan);
  - `app.exit(code)`.
  - Cabang ini berjalan **sebelum** `requestSingleInstanceLock` dan sebelum kode lain, setelah `SKETCHOUT_USER_DATA` diterapkan.

**Test:**
- [ ] `socketPath("/short")` = `/short/mcp.sock`. `userData` sepanjang 120 karakter menghasilkan path di `tmp` yang diakhiri `.sock`, dengan panjang ≤ 100, dan deterministik.
- [ ] `runBridge` dengan server `net` tmp: dua baris stdin sampai ke server, balasan server sampai ke stdout, dan stdin end → resolve 0.
- [ ] Tanpa server: `launchApp` dipanggil sekali. Server baru dibuat setelah 500 ms → tersambung dan pipe berjalan.
- [ ] Tanpa server dan `waitMs: 300`: request `{"id":1,…}` dibalas error -32000, notifikasi tanpa id tidak dibalas, dan stdin end → resolve 1.
- [ ] `LineTransport`: dua pesan dalam satu chunk → dua `onmessage`. Satu pesan terbelah dua chunk → satu `onmessage`. Baris rusak → `onerror`, dan pesan berikutnya tetap terbaca.

  | `view_note` | `{path, maxSize?: 200..1600}` | Konten `{type:"image", data, mimeType:"image/png"}`. |
  | `add_elements` | `{path, elements: z.array(skeleton).min(1).max(500)}` | — |

Pakai `.passthrough()` untuk kunci tambahan yang dikenal Excalidraw.
  - Setiap path melewati `assertGranted` dan setiap dir melewati `assertGrantedDir` **sebelum** router dipanggil.
  - Hasil teks berupa JSON ringkas. Error → `{isError: true, content:[{type:"text", text: pesan}]}`.

  - `listen`, lalu `chmod 0600`;

  - Instruksi server dalam bahasa Inggris (singkat): path absolut dari `get_workspace`/`list_notes`; koordinat dalam piksel kanvas, y ke bawah; elemen tanpa x/y diletakkan otomatis di bawah konten.

**Produces:**

- `interface Env { home: string; exec(cmd: string, args: string[]): Promise<{code: number; stdout: string}>; which(bin: string): Promise<boolean>; exists(p: string): Promise<boolean> }`, dengan `exec` dan `which` lewat `$SHELL -lc` dan argumen di-escape `'…'`.
- `mcpCommand(): {command: string; args: string[]}`:
  - terpaket: `{command: app.getPath("exe"), args: ["--mcp"]}`;
  - dev: `{command: process.execPath, args: [app.getAppPath(), "--mcp"]}`.
- `CLIENTS: Record<ClientId, {label: string; restartNote?: string; status(env, cmd): Promise<ClientStatus>; connect(env, cmd): Promise<void>; disconnect(env): Promise<void>}>`:
  - Klien berbasis CLI (claude-code: `claude mcp add -s user sketch-out -- …`, `claude mcp remove -s user sketch-out`, `claude mcp get sketch-out`; codex: `codex mcp add/remove/get sketch-out`):
    - status `connected` bila keluaran `get` memuat command saat ini;
    - `outdated` bila entri ada tapi command berbeda;
    - connect bila `outdated` = remove lalu add.
  - Klien berbasis JSON memakai `editJsonConfig(file, key: string[], value | undefined)`:
    - parse `JSON.parse` (gagal → `throw new Error("unreadable")`, file tidak disentuh);
    - cadangan `.sketchout.bak` kalau belum ada;
    - set/hapus pada path kunci;
    - `atomicWriteFile` dengan indent 2.
    - Berkas dan kuncinya:
      - claude-desktop: `~/Library/Application Support/Claude/claude_desktop_config.json`, `["mcpServers","sketch-out"]` = `{command, args}`;
      - gemini: `~/.gemini/settings.json`, sama;
      - cursor: `~/.cursor/mcp.json`, sama;
      - vscode: `~/Library/Application Support/Code/User/mcp.json`, `["servers","sketch-out"]` = `{type:"stdio", command, args}`;
      - opencode: `~/.config/opencode/opencode.json`, `["mcp","sketch-out"]` = `{type:"local", command:[command, ...args], enabled:true}`.
- `copyText(kind: "command" | "json"): string`.
- IPC:

  | Channel | Isi |
  |---|---|
  | `ai:clients` | `[{id, label, status, restartNote?}]` |
  | `ai:connect {id}` | → status baru |
  | `ai:disconnect {id}` | → status baru |
  | `ai:copyConfig {kind}` | menulis ke `clipboard` di main dan mengembalikan teksnya |

  `id` divalidasi `z.enum`.
